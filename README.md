# קוד בכיף

דמו חי ב-GitHub Pages:

`https://guynetsereyal.github.io/learn_code_hebrew/`

אב-טיפוס עברי ללימוד עקרונות קוד דרך משחקים קצרים:

- סדר פעולות
- לולאות
- תנאים
- תיקון באגים

## איך מריצים

אפשר לפתוח את `index.html` ישירות בדפדפן, אבל עדיף שרת מקומי קטן:

```bash
python3 -m http.server 4173
```

ואז לגלוש אל:

```text
http://127.0.0.1:4173
```

## פרסום ב-GitHub Pages

הריפו הזה מוכן לפרסום כאתר סטטי דרך GitHub Pages, בלי Vercel.

מה צריך לעשות פעם אחת ב-GitHub:

1. להיכנס ל-`Settings` של הריפו.
2. לפתוח `Pages`.
3. תחת `Build and deployment` לבחור `Source: GitHub Actions`.

אחרי זה, כל push ל-`main` יפרסם אוטומטית את האתר לכתובת:

```text
https://guynetsereyal.github.io/learn_code_hebrew/
```

## מה כבר יש בפנים

- ממשק RTL בעברית
- כמה עולמות ומשימות, לא רק דמו יחיד
- שמירת התקדמות ב-`localStorage`
- תצוגת פסאודו-קוד בעברית
- מעבר ל-JavaScript כדי לגדול בהמשך
- רמזים, כוכבים, מדליות והקראה קולית אם הדפדפן תומך

## כיוון להמשך

- עולם `נחש חכם`
- מצב כתיבה חופשית של קוד אמיתי
- דמויות, סיפור וצלילים
- מצב הורה עם יצירת שלבים חדשים
